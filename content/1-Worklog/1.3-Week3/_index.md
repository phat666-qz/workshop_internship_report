### Week 3 Objectives:

* Master the core concepts of virtual private cloud networking through Amazon Virtual Private Cloud (VPC).
* Analyze IP address structures, network segmentation (Subnetting), and the application of Classless Inter-Domain Routing (CIDR).
* Deploy and configure routing components such as Route Tables and Internet Gateways (IGW) for internet connectivity.
* Evaluate and establish multi-tiered network security layers, effectively combining Security Groups (Stateful) and Network ACLs (Stateless).
* Explore advanced networking features like VPC Peering, VPC Endpoints, and traffic monitoring via VPC Flow Logs.
* Practically construct a complete VPC network architecture from scratch, ensuring seamless connectivity and strict security.
