### Week 4 Objectives:

* Conduct an in-depth exploration of core AWS storage services, including Amazon S3, Amazon EBS, and Amazon EFS.
* Analyze and evaluate the differences between Object Storage, Block Storage, and File Storage models to select optimal solutions.
* Practice deploying and managing Object storage with Amazon S3, dynamically applying suitable Storage Classes.
* Architect a Static Website Hosting solution on Amazon S3, integrating secure access permission configurations.
* Master the basic Custom Domain Mapping process and establish robust Bucket Policies to secure resources from unauthorized access.
