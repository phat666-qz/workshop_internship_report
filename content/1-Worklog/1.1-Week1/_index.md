### Week 1 Objectives:

* Complete onboarding procedures and familiarize with the FCAJ internship guidelines and workflow.
* Master foundational Cloud Computing concepts and distinguish between common service models (IaaS, PaaS, SaaS).
* Analyze the AWS Global Infrastructure architecture, encompassing Regions, Availability Zones (AZs), and Edge Locations.
* Explore cloud-optimized design principles through the AWS Well-Architected Framework.
* Practically set up a new AWS account, ensuring initial foundational security configuration.
* Successfully install and configure the AWS Command Line Interface (CLI) tool to interact with AWS services.
